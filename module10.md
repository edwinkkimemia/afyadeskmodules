## 2. Listening, Terminology, and Formatting That Prevent Fatal Errors

**Listening discipline:** chunk 15 seconds, pause, type, replay drug names/numbers twice with headphones, slow to 0.75x for mumbling/accents, distinguish fifteen/fifty (ask “One-Five or Five-Zero?” logic — replay + flag if still unclear), left/right (replay + note “says left — confirm? flagged”), hyper/hypo (context + spelling check), no/not (dropped negative kills — “no chest pain” vs “chest pain” — replay with waveform zoom, never assume). Log audio quality (1–5) + background + mic used — patterns guide fixes (replace headset, move rooms).

**Terminology on desk:** Module 4 cheat-sheet + drugs.com + Stedman’s abbreviations open always. Verify every drug (Celebrex/Celexa/Cerebyx, Metformin/Metronidazole, Amlodipine/Amitriptyline, Prednisone/Prednisolone — sound-alikes), dose + unit (mg vs mcg 1000x, 5 mg not 5.0, 0.5 not .5), route/frequency (BID vs QID, daily not QD in patient copies), laterality, dates (“14 May 2026” not 05/14). Never guess spelling — flag: “[spelling uncertain — sounds like ‘atenolol’ — flagged, verify with order]” + route to clinician + check EHR meds list for match.

**Formatting to template (copy-paste structure, fill precisely):** Header (patient full + DOB + MRN + date both zones + provider + visit type + location/link + consent noted + audio length), CC (one line reason in patient words), HPI (onset/duration/severity/associated/modifying/factors in chronological bullets), ROS (pertinent positives/negatives as stated, no invention), PMH/PSH/FH/SH/ALL (carry verified today, don’t clone blindly — “verified with patient today” note), MEDS (name dose route frequency verified 100%), Vitals/Exam (as dictated/filed, label patient-reported home devices), Assessment (leave blank / “per clinician” if VA — never diagnose), Plan (admin draft allowed: “Follow-up 2 weeks booked Tue 28 May 10am ET, labs slipped, referral to cardiology sent #..., patient SMS summary sent” + clinical plan verbatim as dictated for signature), Signature line (transcribed by [Name date time-zone] + “AI-assisted draft verified” if applicable + uncertainties count + ready-for-review flag).

Use approved headings, numbered problems (“1. Hypertension — ... 2. Type 2 DM — ...”), metric units, expanded abbreviations in patient copies (“twice daily” not BID), page numbers + “Page 1 of 2” for fax. File to correct encounter + link audio + close task with turnaround logged.

## 3. Accuracy and Proofreading Protocol to >98% (3 Passes, No Skipping)

**Pass 1 — Content (names, numbers, meds, dates, zones):** Verify header (right patient? 2 IDs?), every name spelled (read-back logic: Smith S-M-I-T-H), DOB/date (“14 May 2026” both zones where relevant), phones (NATO repeat), drug name/dose/unit/route/frequency (100% replay + drugs.com + EHR list match), allergies (exact reaction), laterality, consent flag, audio timestamps for uncertainties. Tick each with highlighter (digital comment) — no tick = not verified.

**Pass 2 — Clinical sense (does story hold together?):** If Assessment says MI but Plan says “discharge ibuprofen alone, no cardiology” — STOP, flag urgently to clinician (possible dictation/AI error or missing plan), don’t file silently. Check: problem-plan match (chest pain → ECG/troponin/cardiology, not just “reassured”), med-problem match (insulin without diabetes? query), dose plausibility (Metoprolol 500 mg? — 10× normal, flag), allergy-plan clash (penicillin allergy + amoxicillin ordered? — STAT flag), negative logic (“no chest pain” preserved, not dropped). You don’t diagnose — you catch incongruence and query with SBAR: “Flagging possible mismatch p2: Assessment MI with Plan ibuprofen only — please confirm plan/add cardiology? Holding filing pending review — MK 3pm ET.” This catch saves lives + proves value.

**Pass 3 — Grammar, format, privacy:** Read aloud (catches missing “no,” doubled words, wrong tense), homophones (ileum/ilium, dysphagia/dysphasia,056 → expand), punctuation for meaning (“No, chest pain” vs “No chest pain” — comma kills), template headings + numbering + units + expanded patient abbreviations, PHI in filename? (never `Smith-HIV-note.pdf` emailed — use MRN + encounter + secure portal), chart/encounter linkage correct, task closure note with turnaround + flags. Print-preview for fax (no cut-off), link audio, delete local draft per retention after verified filing.

Speed without skipping: 5-min audio ≈ 30–40 min edit + proofread novice, 20 min experienced. Time yourself, log, improve with text expanders (approved macros for headers, not clinical content), foot pedal/headset shortcuts, dual monitors (audio + EHR). Never rush Pass 1 meds — 2 extra minutes prevents 10× overdose on record.

## 4. Common Fatal Mistakes (Memorize These 7 — Audit Fails You for Any)

1. **Sound-alike drugs:** Celebrex (arthritis) vs Celexa (depression) vs Cerebyx (seizure) — wrong pill for wrong disease. Fix: spell + indication check (“Celexa for depression — matches PMH depression? yes/no, flagged if mismatch”).
2. **Dropped negatives:** “No chest pain, no SOB” typed as “Chest pain, SOB” — creates false emergency + liability. Fix: replay negatives at 0.75x + bold in draft + Pass 2 sense check.
3. **Wrong laterality:** Left knee MRI ordered, right transcribed — wrong surgery side never-event. Fix: replay + note “says left — confirm?” + verify order image side.
4. **Copy-forward cloning:** Old meds/allergies carried without verification (“NKDA” when new penicillin rash occurred). Fix: “verified with patient today” + ask each visit, never blind carry.
5. **Dangerous abbreviations in patient copies:** “Take 5.0 mg QD” → patient takes 50 mg daily. Fix: expand (“Take 5 mg daily”) + ban U/QD/trailing zeros (Module 4).
6. **PHI in filenames/channels:** `Jane-HIV-results.pdf` emailed via Gmail + Anyone link. Fix: MRN + date + type + secure portal + expiry + audit.
7. **AI hallucinations filed unchecked:** AI invents follow-up, dose, allergy denial. Fix: Section 5 verification — replay 100% critical, log AI errors caught.

Each mistake gets a 1-line SOP gate on your wall: “Meds 100% replay + spell + EHR match,” “Negatives bold + replay,” “Laterality confirm + flag,” “No clone without verify-today,” “Expand for patients,” “MRN not name in filename + secure link,” “AI draft ≠ final — verify + sign.”

## 5. AI-Assisted Transcription Rules: Speed With Human Liability

Allowed only on employer-authorized BAA-covered tools (EHR DAX/Abridge/enterprise dictation with signed BAA + training). Never free Otter/ChatGPT/Gemini/phone apps retaining data with PHI — breach + dismissal even if “faster.” Ask onboarding: “Which transcription AI is BAA-covered and authorized for PHI in writing? Retention? Training opt-out? Where are audio/logs stored?” Document answer + policy version.

Prompt for BAA AI (no PHI in prompt beyond authorized audio): “Transcribe verbatim with speaker labels + timestamps every 30 sec, flag uncertain [inaudible HH:MM:SS + best guess + confidence], format SOAP per template, list meds/doses/allergies/plan separately for verification, do not infer diagnosis or invent follow-up.” Then verify: replay 100% meds/allergies/numbers/plan/dates/zones, spot 20% rest, correct hallucinations, add flags, 3-pass proofread, document “AI-assisted draft via [tool] verified by [Name date time-zone], 2 uncertainties flagged p2, ready for clinician signature” + audio ID + turnaround. Reject AI-invented instructions (“Return 2 weeks” not in audio? — delete + flag “AI added follow-up not in audio — confirm desired interval?” + hold filing till confirmed).
