# MODULE 18 — AI FOR THE MODERN MEDICAL VA

> Part of: **AfyaDesk Remote Medical Careers Course**

## Learning Objectives

- Explain AI fundamentals + limits for admin use
- Write effective prompts for email, summaries, automation, research
- Build AI-assisted workflows with human review + confidentiality
- Avoid privacy + clinical risks

## 1. AI Fundamentals (What It Is/Isn't)

LLMs predict text, don't understand patients. Great at drafting, reformatting, brainstorming. Terrible at: knowing your SOP, accessing EHR, verifying insurance, giving safe clinical advice. Hallucinations: invents doses, guidelines, phone numbers – always verify on official source + clinician.

## 2. High-Value VA Uses

- **Email drafting:** "Draft polite no-show follow-up, warm, includes reschedule link placeholder, no PHI" → edit + add specifics in EHR.
- **Summarization (non-PHI):** public payer article → bullet SOP. Never patient chart in public AI.
- **Automation:** "Turn this referral SOP into checklist with owners/dates for Trello" → paste into board.
- **Transcription assist:** only BAA-approved (e.g., EHR DAX) – human verifies 100% meds/plan.
- **Research:** "Compare Athena vs SimplePractice scheduling features for small practice" → verify on vendor sites.
- **Productivity:** Excel formulas, prioritized EOD from bullet dump, meeting agenda.

Prompt formula: Role + Task + Context (no PHI) + Format + Constraints. E.g., "You are a medical admin assistant. Draft 3 SMS reminder variants (<160 chars), polite, include time-zone placeholder, HIPAA-aware, no PHI."

## 3. Quality Control + Privacy Rules

Human-in-loop mandatory: AI drafts, you verify facts/tone/SOP, clinician approves clinical-adjacent, you send via official channel + document. Forbidden: names/DOB/MRN/photos/voice with PHI into ChatGPT/Gemini/free tools; uploading EHR PDFs to summarizers; letting AI message patients directly; acting on AI dosage/triage.

If employer provides HIPAA-compliant Copilot/ChatGPT Team with BAA in writing – use only that for sensitive work, still verify. When in doubt: de-identify fully or don't use AI.

## 4. Final AI Assignment

Design 1-page workflow saving 5+ hrs/week: e.g., "Referral chase automation: Sheet tracker → AI drafts follow-up emails (de-identified template) → VA personalizes in EHR → auto-reminder via task board → weekly report." Include: tool map, prompt library (3 prompts), privacy checkpoint, human approval step, time saved calc, risk + mitigation.

## Common Mistakes

- "AI said so" to patient – never
- Pasting full inbox to "clean up" – breach
- Trusting AI time-zone math – verify in WorldTimeBuddy
